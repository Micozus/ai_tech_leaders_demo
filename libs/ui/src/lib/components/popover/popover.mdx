# Popover

A small panel of optional background opened by a button. Built on PrimeNG, themed by the DevMentor preset.

  <Canvas of={Stories.Playground} story={{ height: '320px' }} />

## What it is for

A popover offers extra explanation without leaving the page, for people who want it.

## When to use

- "How booking works": the two-hour rule and the 24-hour cancellation window (R09, R14).
- A short definition of a term.
- Background that the person does not need to finish the task.

## When not to use

| Situation                           | Use instead      |
| ----------------------------------- | ---------------- |
| Information needed to decide or act | Text on the page |
| A short hint on an icon button      | Tooltip          |
| A decision or a task                | Dialog           |
| An error or a warning               | Alert            |

## Anatomy

| Part    | Required | Notes                                                        |
| ------- | -------- | ------------------------------------------------------------ |
| Trigger | yes      | A ghost button with a visible label                          |
| Panel   | yes      | `radius-overlay`, 1px `line`, `shadow-overlay`, 16px padding |
| Content | yes      | A few sentences                                              |

## Behavior and accessibility

| Topic         | Rule                                                                               | Source                           |
| ------------- | ---------------------------------------------------------------------------------- | -------------------------------- |
| Keyboard      | Enter or Space opens; Esc closes; Tab moves through the content                    | WAI-ARIA APG: Dialog (non-modal) |
| Focus order   | The panel follows the trigger in the order                                         | WCAG 2.4.3                       |
| Role and name | Trigger `aria-haspopup="dialog"`; panel `role="dialog"` named by the trigger label | WCAG 4.1.2                       |
| Screen reader | Announces the label, then the content                                              | WAI-ARIA                         |
| Dismissal     | Esc or a click outside closes it; hover is not required                            | WCAG 1.4.13                      |
| Target size   | The trigger is 40px high                                                           | WCAG 2.5.8                       |

## API

| Input    | Type     | Default  | Description                     |
| -------- | -------- | -------- | ------------------------------- |
| label    | `string` | required | Trigger text and the panel name |
| appendTo | `string` | `body`   | Where the panel renders         |

Selector: `ui-popover`. The panel content is projected.

## Code

Minimal:

```html
<ui-popover label="How booking works"><p class="text-body">…</p></ui-popover>
```

In DevMentor:

```html
<ui-popover label="How booking works">
  <p class="max-w-measure text-body">
    A slot must start at least two hours after it is booked. Free cancellation
    ends 24 hours before the session.
  </p>
</ui-popover>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '320px' }} />
</Unstyled>

- Only optional background lives in a popover. Source: task rule.
- Closes with Esc and a click outside; hover is not required. Source: WCAG 1.4.13.
- Never an error or a decision. Source: task rule.
