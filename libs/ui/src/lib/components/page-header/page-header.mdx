# Page header

The title block of a page: an optional eyebrow, the heading, an optional description and the page actions.

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '240px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

Every page says where the person is, in one `h1`, and where its main actions are.

## When to use

- The top of every page below the app header.
- To place page-level actions, such as Save or Find a mentor.

## When not to use

| Situation               | Use instead                                 |
| ----------------------- | ------------------------------------------- |
| A section inside a page | Card heading or a section title             |
| A greeting              | Nothing: the page title says where they are |
| A navigation bar        | App header                                  |

## Anatomy

| Part        | Required             | Notes                                         |
| ----------- | -------------------- | --------------------------------------------- |
| Eyebrow     | Text (accent, label) | Optional: the role or the area, e.g. "Mentor" |
| Heading     | `h1`                 | One per page                                  |
| Description | Text (muted)         | Optional, one short sentence                  |
| Actions     | Projected            | Buttons on the right; below on narrow screens |

## Variants

One look; the parts are optional.

| Variant          | Choose it when                              | Source   |
| ---------------- | ------------------------------------------- | -------- |
| title only       | Most pages                                  | R01.1    |
| with description | When the page needs one sentence of context | proposal |
| with actions     | Pages with a main or common action          | R01.3    |

## Behavior and accessibility

| Topic       | Rule                                           | Source            |
| ----------- | ---------------------------------------------- | ----------------- |
| Heading     | Exactly one `h1` per page                      | WCAG 1.3.1, 2.4.6 |
| Order       | Actions follow the title in the reading order  | WCAG 2.4.3        |
| Landmark    | A `header` inside `main`                       | WCAG 1.3.1        |
| Keyboard    | Actions are reachable with Tab                 | WAI-ARIA          |
| Colour      | The eyebrow is `accent` on the canvas (4.76:1) | WCAG 1.4.3        |
| Target size | Actions are standard buttons                   | WCAG 2.5.8        |

## Content

| Topic            | Rule                                           | Source    |
| ---------------- | ---------------------------------------------- | --------- |
| Heading          | A noun phrase naming the page: "Your sessions" | task rule |
| Description      | One sentence; no greeting                      | proposal  |
| Eyebrow          | A word or two                                  | proposal  |
| Longer languages | Wraps; the actions move below                  | proposal  |

## API

| Input       | Type     | Default  | Description                |
| ----------- | -------- | -------- | -------------------------- |
| heading     | `string` | required | The page title             |
| eyebrow     | `string` | `""`     | Small line above the title |
| description | `string` | `""`     | One sentence below         |

Selector: `ui-page-header`. Actions are projected.

## Code

Minimal:

```html
<ui-page-header heading="Your sessions" />
```

In DevMentor:

```html
<ui-page-header
  eyebrow="Mentor"
  heading="Set up your mentor page"
  description="Publish at least one bookable session within two weeks."
>
  <button ui-button>Save</button>
</ui-page-header>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '400px' }} />
</Unstyled>

- One `h1` per page. Source: WCAG 1.3.1.
- No centered greeting. Source: A01.
- Keep the description to one sentence. Source: proposal.
