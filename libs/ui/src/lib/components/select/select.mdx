# Select

A native `<select>` with the DevMentor look. The list and the arrow belong to the platform, so it works with keyboard, touch and screen readers as is.

## What it is for

A select lets a person choose one value from a list that is too long to show.

## When to use

- A time zone for a mentor's slots (E02-S03): many values, one choice.
- A country for payouts (E02-S05).
- Any choice of one from six or more options.

## When not to use

| Situation                                         | Use instead                                    |
| ------------------------------------------------- | ---------------------------------------------- |
| Two to five options (25 or 50 minutes, stack tag) | Radio group (one choice) or Checkbox (several) |
| A long list the user must search                  | A combobox: not built, see "What is missing"   |
| A list of actions                                 | Menu                                           |
| Several values at once                            | Checkbox group                                 |

## Anatomy

| Part           | Required            | Notes                                                                        |
| -------------- | ------------------- | ---------------------------------------------------------------------------- |
| Label          | yes (in `ui-field`) | Always visible                                                               |
| Control        | yes                 | Native `<select>`, 40px high; the arrow and the open list are the platform's |
| Options        | yes                 | Plain text; one may be an empty "Choose…" option                             |
| Hint and error | no                  | As in the text field                                                         |

**Disabled:** the select is dimmed and a hint says why (for example "This mentor offers only 50-minute sessions"). Source: Q-A.

## Behavior and accessibility

| Topic         | Rule                                                                                  | Source                |
| ------------- | ------------------------------------------------------------------------------------- | --------------------- |
| Keyboard      | Tab focuses; Arrow keys change the value on desktop; Space or Alt+Down opens the list | WAI-ARIA APG (native) |
| Focus order   | Visual order                                                                          | WCAG 2.4.3            |
| Role and name | Native combobox/listbox; named by its label                                           | WCAG 4.1.2            |
| Invalid       | `aria-invalid="true"` plus an error                                                   | WCAG 3.3.1            |
| Screen reader | Announces the label, the selected value and the number of options                     | native                |
| Target size   | 40px high                                                                             | WCAG 2.5.8            |

## Content

## API

| Input   | Type      | Default | Description                      |
| ------- | --------- | ------- | -------------------------------- |
| invalid | `boolean` | `false` | Danger border and `aria-invalid` |

Selector: `select[ui-select]`. Options, `disabled`, `required` and forms bindings stay native.

## Code

Minimal:

```html
<select ui-select id="tz">
  <option>Europe/Warsaw</option>
</select>
```

In DevMentor:

```html
<ui-field label="Time zone" controlId="tz">
  <select ui-select id="tz">
    <option>Europe/Warsaw</option>
    <option>America/New_York</option>
  </select>
</ui-field>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '360px' }} />
</Unstyled>

- Use a select for six or more options. Source: proposal, WAI-ARIA APG.
- Do not use a select for two or three options. Source: proposal.
- A visible label on every select. Source: task rule.
