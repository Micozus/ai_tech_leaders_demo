# Spinner

A small rotating indicator for a short wait. It stands beside words that say what is happening.

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '200px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

A spinner shows that something is happening when the wait is short and the shape of the result is unknown.

## When to use

- Inside a button that is saving (the `loading` state).
- Next to a status text: "Saving your prices".

## When not to use

| Situation                            | Use instead                                 |
| ------------------------------------ | ------------------------------------------- |
| A list or a page that loads          | Skeleton in the shape of the content        |
| A wait longer than about ten seconds | Error state with a retry                    |
| Progress that can be measured        | Not built; there are no progress bars (A02) |

## Anatomy

| Part | Required     | Notes                                   |
| ---- | ------------ | --------------------------------------- |
| Ring | span         | 16px, `line` track and an `accent` head |
| Name | `aria-label` | "Loading"                               |

## Behavior and accessibility

| Topic       | Rule                                          | Source     |
| ----------- | --------------------------------------------- | ---------- |
| Role        | `role="status"` with `aria-label="Loading"`   | WCAG 4.1.3 |
| Words       | Pair it with text that says what is happening | WCAG 1.1.1 |
| Motion      | Rotation stops under reduced motion           | WCAG 2.3.3 |
| Keyboard    | Not focusable                                 | n/a        |
| Colour      | A ring, not colour alone                      | WCAG 1.4.1 |
| Target size | Not a target                                  | n/a        |

## Code

Minimal:



## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '320px' }} />
</Unstyled>

- A spinner sits next to words. Source: WCAG 1.1.1.
- A list that loads uses a skeleton. Source: task rule.
- No progress bars. Source: A02.
