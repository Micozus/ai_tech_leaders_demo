# Link

A native `<a>` styled as text. It goes somewhere: another page, a mentor's public work, the cancellation rules.

## What it is for

A link lets a person read more or open something without leaving a decision half-made.

## When to use

- Inside a sentence: "Read the cancellation rules before you book".
- A public-work link on a mentor page (E02-S02).
- Navigation between pages that are not the main action of the screen.

## When not to use

| Situation                                              | Use instead            |
| ------------------------------------------------------ | ---------------------- |
| Doing something (booking, saving, deleting)            | Button                 |
| Going to another page as the main action of the screen | `a[ui-button]` primary |
| A list of actions on a row                             | Button, ghost variant  |
| Opening a menu                                         | Menu                   |

## Anatomy

| Part          | Required | Notes                                                       |
| ------------- | -------- | ----------------------------------------------------------- |
| Text          | yes      | Describes the destination; never "click here"               |
| Underline     | yes      | Always visible: colour is not the only signal               |
| External icon | no       | Not built; add `pi-external-link` beside the text if needed |

## Variants

There is one link style. A link that looks like a button is a button (`a[ui-button]`).

| Variant | Choose it when | Source |
| ------- | -------------- | ------ |
| default | All links      | R01.3  |

## Behavior and accessibility

| Topic         | Rule                                                                                       | Source             |
| ------------- | ------------------------------------------------------------------------------------------ | ------------------ |
| Keyboard      | Tab focuses; Enter follows the link                                                        | WAI-ARIA APG: Link |
| Focus order   | Follows the reading order                                                                  | WCAG 2.4.3         |
| Role and name | Native `a` with an `href`; the text is the name                                            | WCAG 2.4.4, 4.1.2  |
| Screen reader | Announces "Cancellation rules, link"                                                       | WAI-ARIA           |
| Colour        | Underline keeps it distinguishable without colour                                          | WCAG 1.4.1         |

## API

| Input  | Type | Default | Description                                                                   |
| ------ | ---- | ------- | ----------------------------------------------------------------------------- |
| (none) |      |         | The component only styles `a[ui-link]`. `href`, `target` and `rel` are native |

Selector: `a[ui-link]`. For links that open another site add `rel="noopener noreferrer"` and `target="_blank"` with a visible hint.

## Code

Minimal:

```html
<a ui-link href="/rules">cancellation rules</a>
```

In DevMentor:

```html
<p class="text-body">
  Public work:
  <a
    ui-link
    class="font-mono text-code"
    href="https://github.com/acme/billing-service/pull/412"
    >github.com/acme/billing-service/pull/412</a
  >
</p>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '260px' }} />
</Unstyled>

- Link text names the destination. Source: WCAG 2.4.4.
- A link keeps its underline. Source: WCAG 1.4.1.
- Never use a link for an action that changes data. Source: WAI-ARIA APG.
