# Button

A native `<button>` (or `<a>`) with the DevMentor look. It starts an action: book, pay, publish, approve.

## What it is for

A button lets a person do the one thing a screen is for, or step away from it. It answers "what can I do here?" with a verb.

## When to use

- The main action of a screen area: **Book a session**, **Publish slots**, **Approve note** (primary). Source: R01.3.
- A secondary action next to it: **Cancel booking**, **Back** (quiet).
- A destructive action that leaves the screen: **Cancel booking** in a confirmation (danger). Source: R09.
- A low-key action inside a row or a sentence: **Copy link**, **Edit** (ghost, the text action).

## When not to use

| Situation                                    | Use instead                                                                         |
| -------------------------------------------- | ----------------------------------------------------------------------------------- |
| Going to another page or a URL               | Link (`a[ui-link]`), or `a[ui-button]` only when the page change is the main action |
| Choosing one of two or three visible options | Radio group                                                                         |
| Turning an option on for a form              | Checkbox                                                                            |
| Showing a hint or an error                   | Field hint or error, Alert                                                          |
| A choice from a long list                    | Select                                                                              |

## Anatomy

| Part        | Required      | Notes                                                                |
| ----------- | ------------- | -------------------------------------------------------------------- |
| Label       | yes           | A verb and an object. Visible text, never icon-only in 1.0           |
| Icon        | no            | From PrimeIcons, 16px, left of the label, decorative (`aria-hidden`) |
| Spinner     | no            | Appears while `loading`; the label stays                             |
| Reason text | when disabled | Next to the button, not inside it                                    |

## Variants

Pick by the role of the action, not by colour.

| Variant | Choose it when                                                          | Source   |
| ------- | ----------------------------------------------------------------------- | -------- |
| primary | The main action of a screen area. At most one per area.                 | R01.3    |
| soft    | A secondary action that should still stand out (e.g. Edit mentor page). | proposal |
| quiet   | A neutral secondary action: Cancel, Back, Skip.                         | R01.3    |
| danger  | An action that cannot be undone or costs money (Cancel booking).        | R09      |
| ghost   | A text action inside a row or a sentence: Copy link.                    | R01.1    |

## States

<Unstyled>
  <Canvas of={Stories.StateMatrix} story={{ height: '520px' }} />
</Unstyled>

Hover, focus and pressed are frozen previews built from the component's own hover and focus declarations (documentation only).

| State    | What changes                                                              | Source         |
| -------- | ------------------------------------------------------------------------- | -------------- |
| Default  | Filled or outlined per variant, 40px high (32px small)                    | D1             |
| Hover    | Colour and border change in 130ms. No lift or movement                    | D8, R02.3      |
| Focus    | 3px `focus` ring, 2px offset, on every variant                            | D6, WCAG 2.4.7 |
| Pressed  | Main action turns `accent-pressed`; others deepen their border or fill    | D10            |
| Disabled | 50% opacity, `not-allowed` cursor, reason as text beside it               | D9             |
| Loading  | Spinner before the label, `aria-busy`, clicks ignored, text stays legible | WCAG 1.4.3     |
| Selected | Not applicable: a button is not a toggle (use a checkbox)                 | n/a            |
| Error    | Not applicable: errors belong to the field or an alert                    | n/a            |

**Disabled:** the reason is always written next to the button (for example "Pick a slot first"), never only in a tooltip. Source: stage 2 decision Q-A, WCAG 3.3.2.

## Behavior and accessibility

| Topic         | Rule                                                                                                                                                                   | Source               |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| Keyboard      | Tab focuses it; Enter and Space activate a `<button>`; Enter activates an `<a>`                                                                                        | WAI-ARIA APG: Button |
| Focus order   | Follows the visual order; the main action comes last in a form, after Cancel                                                                                           | WCAG 2.4.3           |
| Role and name | Native `button` or `a`; the name is the label. Icon-only buttons need `aria-label`                                                                                     | WCAG 4.1.2           |
| Loading       | `aria-busy="true"`; a loading button must still not be activated again (pointer events off). Keyboard activation is not blocked by the component: guard in the handler | WCAG 4.1.3           |
| Screen reader | Announces "Book a session, button". A disabled button is announced as dimmed                                                                                           | WAI-ARIA             |
| Target size   | At least 40 × 32px, above the 24 × 24px minimum                                                                                                                        | WCAG 2.5.8           |

## Content

| Topic            | Rule                                                                                        | Source           |
| ---------------- | ------------------------------------------------------------------------------------------- | ---------------- |
| Label            | Verb plus object: "Book a session", "Publish slots", "Approve note". Never "OK" or "Submit" | R01.3, task rule |
| Length           | Up to about 28 characters; longer text wraps                                                | proposal         |
| Numbers          | Include the amount when money moves: "Pay €45.00"                                           | R09              |
| Longer languages | The button grows in width; it never truncates the label                                     | proposal         |

## API

| Input   | Type                                          | Default   | Description                                                 |
| ------- | --------------------------------------------- | --------- | ----------------------------------------------------------- |
| variant | `primary \| soft \| quiet \| danger \| ghost` | `primary` | Role of the action                                          |
| size    | `md \| sm`                                    | `md`      | 40px or 32px (dense lists)                                  |
| block   | `boolean`                                     | `false`   | Full width                                                  |
| loading | `boolean`                                     | `false`   | Shows the spinner, sets `aria-busy`, ignores pointer events |

Native attributes (`type`, `disabled`, `href`, `aria-*`) stay on the element. Selector: `button[ui-button], a[ui-button]`.

## Code

Minimal:

```html
<button ui-button>Book a session</button>
```

In DevMentor:

```html
<div class="flex gap-group">
  <button ui-button type="submit" [loading]="booking()">Pay €45.00</button>
  <button ui-button variant="quiet" type="button">Cancel</button>
</div>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '320px' }} />
</Unstyled>

- One primary per screen area. Source: R01.3.
- A verb and an object in every label. Source: task rule, WCAG 2.4.6.
- A disabled button needs its reason in text. Source: Q-A, WCAG 3.3.2.
- No gradient, glow or lift on a button. Source: A01, D8.
