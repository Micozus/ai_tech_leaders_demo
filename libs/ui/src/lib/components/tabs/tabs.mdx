# Tabs

A row of tabs that switches between views of the same page. Built on PrimeNG, themed by the DevMentor preset.

## What it is for

Tabs let a person move between a few parallel views without leaving the page or losing their place.

## When to use

- Upcoming and past sessions on a mentee home (E03-S04).
- Sections of a settings page that share one heading.
- Two to five parallel views.

## When not to use

| Situation                            | Use instead                                                  |
| ------------------------------------ | ------------------------------------------------------------ |
| Steps in a flow (pick, pay, confirm) | A stepper or separate pages: steps are ordered, tabs are not |
| Views with their own address         | Pages with navigation links                                  |
| Many views                           | A select or a list                                           |
| Filtering a list                     | Checkboxes                                                   |

## Anatomy

| Part     | Required | Notes                                                                |
| -------- | -------- | -------------------------------------------------------------------- |
| Tab list | yes      | Tabs with 1px bottom line; the active tab has a 2px accent underline |
| Tab      | yes      | A label, 40px high, bold                                             |
| Panel    | yes      | The content of the selected tab                                      |

## Behavior and accessibility

| Topic         | Rule                                                                                | Source             |
| ------------- | ----------------------------------------------------------------------------------- | ------------------ |
| Keyboard      | Tab enters the tab list; Arrow Left and Right move and select; Tab enters the panel | WAI-ARIA APG: Tabs |
| Focus order   | One tab stop for the list, then the panel                                           | WCAG 2.4.3         |
| Role and name | `tablist`, `tab` with `aria-selected`, `tabpanel` labelled by its tab               | WCAG 4.1.2         |
| Screen reader | Announces "Past, tab, 2 of 2, selected"                                             | WAI-ARIA           |
| Colour        | The selected tab also has an underline and `aria-selected`                          | WCAG 1.4.1         |
| Target size   | Tabs are 40px high                                                                  | WCAG 2.5.8         |

## API

| Input              | Type               | Default   | Description             |
| ------------------ | ------------------ | --------- | ----------------------- |
| value              | `string` (two-way) | first tab | The selected tab        |
| ui-tab-panel value | `string`           | required  | Identifier of the panel |
| ui-tab-panel label | `string`           | required  | Text of the tab         |

Selectors: `ui-tabs` and `ui-tab-panel` (children). Panel content is projected.

## Code

Minimal:

```html
<ui-tabs>
  <ui-tab-panel value="upcoming" label="Upcoming">…</ui-tab-panel>
  <ui-tab-panel value="past" label="Past">…</ui-tab-panel>
</ui-tabs>
```

In DevMentor:

```html
<ui-tabs [(value)]="view">
  <ui-tab-panel value="upcoming" label="Upcoming"
    ><!-- upcoming session rows --></ui-tab-panel
  >
  <ui-tab-panel value="past" label="Past"
    ><!-- past sessions and written answers --></ui-tab-panel
  >
</ui-tabs>
```
