# Async region

One block for the four states of data that loads: loading, empty, error, and the content.

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '300px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

Every list and detail in the product loads, can be empty and can fail. The async region makes them all behave the same.

## When to use

- Around any list or detail whose data arrives later: sessions, slots, mentors, messages.
- Whenever the empty and error texts need to differ from the default.

## When not to use

| Situation                | Use instead                       |
| ------------------------ | --------------------------------- |
| A form that submits      | Form pattern with its own states  |
| A short wait on a button | The `loading` state of the button |
| Static content           | Nothing: render the content       |

## Anatomy

| Part    | Required                  | Notes                                                         |
| ------- | ------------------------- | ------------------------------------------------------------- |
| Loading | Status text and skeletons | `aria-busy` and a text that says what loads                   |
| Empty   | Empty state               | Heading, description and a projected action (`uiEmptyAction`) |
| Error   | Error state               | Heading, description and a projected action (`uiErrorAction`) |
| Content | Projected                 | Shown when ready                                              |

## Variants

The state is an input; the texts are inputs.

| Variant | Choose it when                                            | Source     |
| ------- | --------------------------------------------------------- | ---------- |
| loading | Data is on its way                                        | WCAG 4.1.3 |
| empty   | Loaded and there is nothing: say why and give a next step | task rule  |
| error   | Loading failed: say what and offer a retry                | task rule  |
| ready   | Show the content                                          | n/a        |

## States

<Unstyled>
  <Canvas of={Stories.StateMatrix} story={{ height: '1300px' }} />
</Unstyled>

Hover, focus and pressed are frozen previews built from the component's own hover and focus declarations (documentation only).

| State                   | What changes                                     | Source   |
| ----------------------- | ------------------------------------------------ | -------- |
| Loading                 | Skeletons and "Loading sessions"                 | D19, Q-B |
| Empty                   | Dashed panel with a reason and an action         | D17      |
| Error                   | Danger panel announced as an alert, with a retry | D22      |
| Ready                   | The content                                      | n/a      |
| Hover / Focus / Pressed | Belong to the projected actions                  | n/a      |
| Disabled / Selected     | Not applicable                                   | n/a      |

**Disabled:** the region itself is never disabled; its actions may be, with the reason in text.

## Behavior and accessibility

| Topic       | Rule                                                                                     | Source     |
| ----------- | ---------------------------------------------------------------------------------------- | ---------- |
| Keyboard    | The projected actions are reachable with Tab                                             | WAI-ARIA   |
| Loading     | `aria-busy="true"` and a status text announce the load                                   | WCAG 4.1.3 |
| Error       | `role="alert"` announces the failure                                                     | WCAG 4.1.3 |
| Focus       | Content that replaces content keeps focus where it can: put the retry first in the error | WCAG 2.4.3 |
| Motion      | Skeletons are static under reduced motion                                                | WCAG 2.3.3 |
| Target size | Actions are standard 40px buttons                                                        | WCAG 2.5.8 |

## Content

| Topic         | Rule                                                                                      | Source     |
| ------------- | ----------------------------------------------------------------------------------------- | ---------- |
| Loading label | Say what loads: "Loading sessions"                                                        | WCAG 4.1.3 |
| Empty         | Why and what next: "No sessions yet. Book a mentor to get your first written answer."     | task rule  |
| Error         | What failed and what to do: "Sessions did not load. Check your connection and try again." | WCAG 3.3.3 |
| Never         | "Nothing here" or "Something went wrong" alone                                            | task rule  |

## API

| Input                           | Type                                 | Default   | Description               |
| ------------------------------- | ------------------------------------ | --------- | ------------------------- |
| state                           | `loading \| empty \| error \| ready` | `ready`   | Which state to show       |
| loadingLabel                    | `string`                             | `Loading` | Status text while loading |
| emptyHeading / emptyDescription | `string`                             | generic   | Empty state text          |
| errorHeading / errorDescription | `string`                             | generic   | Error state text          |

Selector: `ui-async-region`. Project the content, `uiEmptyAction` and `uiErrorAction` items.

## Code

Minimal:

```html
<ui-async-region [state]="state()">…content…</ui-async-region>
```

In DevMentor:

```html
<ui-async-region
  [state]="state()"
  loadingLabel="Loading sessions"
  emptyHeading="No sessions yet"
  emptyDescription="Book a mentor to get your first written answer."
  errorHeading="Sessions did not load"
>
  @for (s of sessions(); track s.id) { <ui-session-row [session]="s" /> }
  <button uiEmptyAction ui-button>Find a mentor</button>
  <button uiErrorAction ui-button variant="quiet" (click)="reload()">
    Try again
  </button>
</ui-async-region>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '460px' }} />
</Unstyled>

- Say what loads, what is missing, what failed. Source: task rule, WCAG 4.1.3.
- Always give the next step. Source: task rule.
- One component for all lists. Source: engineering standards (single source of truth).
