# Avatar

An initials avatar: a flat square with the first letters of a name. It stands for a person next to their name.

<Unstyled>

</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

An avatar helps recognise a person at a glance in a list, a session or a header.

## When to use

- Next to a mentor in the list and on a mentor page (E03-S01).
- Next to the author of a message or a note, with the time (R02.2).
- In the account menu.

## When not to use

| Situation                   | Use instead           |
| --------------------------- | --------------------- |
| Decoration without a person | Nothing               |
| A photo (not built)         | See "What is missing" |
| A group of people           | Not built             |

## Anatomy

| Part            | Required | Notes                                     |
| --------------- | -------- | ----------------------------------------- |
| Initials        | yes      | Up to two letters of the name, decorative |
| Border          | yes      | 1px `line`                                |
| Accessible name | yes      | The full name, `role="img"`               |

## Variants

Sizes only. A flat fill: no gradient (P11), no circle (A01).

| Variant | Choose it when              | Source   |
| ------- | --------------------------- | -------- |
| sm      | 40px: rows, menus           | proposal |
| md      | 56px: list rows and headers | proposal |
| lg      | 80px: a profile page        | proposal |

## Behavior and accessibility

| Topic         | Rule                                                        | Source     |
| ------------- | ----------------------------------------------------------- | ---------- |
| Keyboard      | Not focusable                                               | WAI-ARIA   |
| Focus order   | Not in the order                                            | n/a        |
| Role and name | `role="img"` with the full name; initials are `aria-hidden` | WCAG 1.1.1 |
| Screen reader | Announces "Ada Lovelace, image"                             | WAI-ARIA   |
| Contrast      | Initials are `ink` on `surface-muted` (15.5:1)              | WCAG 1.4.3 |
| Target size   | Not a target                                                | n/a        |

## Content

| Topic            | Rule                                                          | Source     |
| ---------------- | ------------------------------------------------------------- | ---------- |
| Initials         | First letters of up to two words, upper case                  | proposal   |
| Name             | Show the full name next to the avatar; never the avatar alone | WCAG 1.1.1 |
| Long names       | Initials stay two letters; the name next to it wraps          | proposal   |
| Longer languages | Works with any script that has letters                        | proposal   |

## API

| Input | Type             | Default  | Description        |
| ----- | ---------------- | -------- | ------------------ |
| name  | `string`         | required | Full display name  |
| size  | `sm \| md \| lg` | `md`     | 40px, 56px or 80px |

Selector: `ui-avatar`.

## Code

Minimal:

```html
<ui-avatar name="Ada Lovelace" />
```

In DevMentor:

```html
<div class="flex items-center gap-groups">
  <ui-avatar name="Ada Lovelace" />
  <div>
    <p class="text-label">Ada Lovelace</p>
    <p class="text-meta text-muted">TypeScript · React</p>
  </div>
</div>
```

## Do and don't

<Unstyled>
  <Canvas of={Stories.DoAndDont} story={{ height: '320px' }} />
</Unstyled>

- Flat fill, no gradient. Source: P11, A01.
- Square with `radius-control`, never a full circle. Source: A01.
- Always with the name next to it. Source: WCAG 1.1.1.
