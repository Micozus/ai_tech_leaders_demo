# Share link field

The mentor's share link with a copy button.

Backlog: E02-S02 (#21)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '260px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

Mentors share their page with their own audience; copying should be one action.

## When to use

- After the mentor page is saved, on the mentor home.

## When not to use

| Situation              | Use instead                    |
| ---------------------- | ------------------------------ |
| Editing a URL          | Text field                     |
| Telling copy succeeded | Emit `copied` and show a toast |

## Anatomy

| Part           | Component              | Notes                   |
| -------------- | ---------------------- | ----------------------- |
| Label and hint | Field                  | "Your share link"       |
| Link           | Text field (read only) | The full URL            |
| Copy           | Button (quiet)         | `pi-copy` + "Copy link" |

## Data states

  <Canvas of={Stories.StateMatrix} story={{ height: '260px' }} />

| State     | What the person sees                                            | Story           |
| --------- | --------------------------------------------------------------- | --------------- |
| Default   | Link and button                                                 | Playground      |
| Copied    | `copied` is emitted; the page shows a toast "Share link copied" | Copies The Link |
| Long link | The input scrolls; the button stays                             | Long Text       |

| Topic        | Rule                                                                    | Source     |

## API

| Input or output | Type     | Default  | Description    |
| --------------- | -------- | -------- | -------------- |
| url             | `string` | required | The link       |

## Code

```html

  [url]="url"
  (copied)="toast.show({ tone: 'success', summary: 'Share link copied' })"
```
