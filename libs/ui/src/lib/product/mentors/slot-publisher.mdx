# Slot publisher

The mentor's published slots, free or booked, and a row to add one.

Backlog: E02-S03 (#22)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '520px' }} />

<Controls of={Stories.Playground} />

## What it is for

Slots are what makes a mentor bookable. The mentor must see which are taken.

## When to use

- The mentor home and the mentor set-up screen.

## When not to use

| Situation              | Use instead                                       |
| ---------------------- | ------------------------------------------------- |
| Recurring hours        | Not built: single slots only (backlog assumption) |
| Picking a slot to book | Slot picker                                       |

## API

| Input or output             | Type         | Default         | Description                  |
| --------------------------- | ------------ | --------------- | ---------------------------- |
| slots                       | `Slot[]`     | `[]`            | Published slots              |
| state                       | `AsyncState` | `ready`         | Loading, empty, error, ready |
| timeZone                    | `string`     | `Europe/Warsaw` | IANA zone for display        |
| publish / unpublish / retry | `output`     |                 | Events                       |

## Code

```html
<ui-slot-publisher
  [slots]="slots()"
  [state]="state()"
  (publish)="add($event)"
  (unpublish)="remove($event)"
  (retry)="reload()"
/>
```
