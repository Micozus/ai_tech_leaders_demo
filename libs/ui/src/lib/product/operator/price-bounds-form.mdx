# Price bounds form

The operator sets the price bounds and the platform fee.

Backlog: E05-S02 (#36), 1.1

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '900px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

R08 and R10: mentors price within operator bounds; the fee is configurable.

## When to use

- The operator settings screen.

## When not to use

| Situation         | Use instead |
| ----------------- | ----------- |
| A mentor's prices | Price form  |

## Anatomy

| Part        | Component          | Notes                                                         |
| ----------- | ------------------ | ------------------------------------------------------------- |
| Five fields | Field + Text field | Lowest and highest for 25 and 50 minutes, and the fee percent |
| Save        | Button             | "Save bounds and fee"                                         |
