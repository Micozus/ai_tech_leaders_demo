# Dispute record form

The operator records how a quality dispute was resolved.

Backlog: E05-S03 (#37), 1.1

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '700px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

R09: no automatic refunds. A refund is paid by hand and written down; the outcome goes in the shared operator note (R18).

## When to use

- After the founders have decided a dispute.

## When not to use

| Situation           | Use instead     |
| ------------------- | --------------- |
| An automatic refund | Not built (R09) |

## Anatomy

| Part    | Component        | Notes                                                           |
| ------- | ---------------- | --------------------------------------------------------------- |
| Outcome | Radio group      | Refund paid by hand, No refund, Mentor asked to redo the answer |
| Notes   | Field + Textarea | Required                                                        |
| Record  | Button           | "Record outcome"                                                |
