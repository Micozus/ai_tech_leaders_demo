# Invitation batch table

A batch of invitations and who published a slot.

Backlog: E05-S01 (#35), 1.1

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '520px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

R17: invitations go out in batches of 20; fewer than 5 mentors publishing in two weeks stops further invitations.

## When to use

- The operator's invitations screen.

## When not to use

| Situation        | Use instead                                                   |
| ---------------- | ------------------------------------------------------------- |
| Inviting someone | The operator does it by hand until the story ships (D19, R18) |

## Anatomy

| Part    | Component     | Notes                                        |
| ------- | ------------- | -------------------------------------------- |
| Caption | Table caption | "Invitation batch: N of 20 published a slot" |
| Rows    | Table rows    | Email as row header, status badge            |
