# Slot picker

Choose 25 or 50 minutes at the mentor's price, and a slot that starts at least two hours ahead.

Backlog: E03-S02 (#26)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '620px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

R14: a slot under two hours away cannot be booked. The picker says so in text beside the slot.

## When to use

- The first step of the booking flow.

## When not to use

| Situation        | Use instead    |
| ---------------- | -------------- |
| Publishing slots | Slot publisher |

## Anatomy

| Part   | Component   | Notes                                                                  |
| ------ | ----------- | ---------------------------------------------------------------------- |
| Length | Radio group | 25 and 50 minutes with prices                                          |
| Slots  | Radio group | Time in the mentor's zone; unavailable ones are disabled with a reason |

## API

| Input or output     | Type           | Default    | Description                                |
| ------------------- | -------------- | ---------- | ------------------------------------------ |
| slots               | `Slot[]`       | required   | Offered slots                              |
| now                 | `string` (ISO) | required   | Now, passed in so the screen is repeatable |
| price25 / price50   | `number`       | required   | Prices                                     |
| length / selectedId | `model`        | 50 / empty | The choices                                |

## Code

```html
<ui-slot-picker
  [slots]="slots()"
  [now]="now"
  [price25]="25"
  [price50]="45"
  [(length)]="length"
  [(selectedId)]="slotId"
/>
```
