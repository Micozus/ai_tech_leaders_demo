# Mentor list row

One mentor in the list: name, stack tags, public work, lowest price, next free slot.

Backlog: E03-S01 (#25)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '260px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

The mentee chooses from the mentor's work and tags, never from a score (N02, R13).

## When to use

- Rows of the mentor list, separated by a 1px line.

## When not to use

| Situation          | Use instead          |
| ------------------ | -------------------- |
| A rating or rank   | Not built (N02, A03) |
| A full mentor page | Mentor detail        |

## Anatomy

| Part           | Component        | Notes                         |
| -------------- | ---------------- | ----------------------------- |
| Avatar         | Avatar (md)      | Initials                      |
| Name           | Heading (h3)     | Full name                     |
| Tags           | Badges (neutral) | Stack tags                    |
| Public work    | Link (mono)      | The mentor's URL              |
| Price and slot | Text             | "From €25.00", next free slot |
| Action         | Button (small)   | "View mentor"                 |

## Behavior and accessibility

| Topic     | Rule                              | Source     |
| --------- | --------------------------------- | ---------- |
| Structure | An `article` with an `h3`         | WCAG 1.3.1 |
| Link      | The URL is the link text          | WCAG 2.4.4 |
| No score  | No stars, counts or rank anywhere | N02        |
