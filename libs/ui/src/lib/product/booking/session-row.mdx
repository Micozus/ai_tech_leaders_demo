# Session row

One session in a list: who, what, when, status, and what you can do.

Backlog: E03-S04 (#28)

## What it is for

The mentee and the mentor see their upcoming and past sessions at a glance.

## When to use

- Lists of sessions on the mentee and mentor homes.

## When not to use

| Situation        | Use instead   |
| ---------------- | ------------- |
| A session screen | Session panel |

## Anatomy

| Part           | Component       | Notes                                          |
| -------------- | --------------- | ---------------------------------------------- |
| Avatar         | Avatar (small)  | The other person                               |
| Title and meta | Text            | Session title, name, time, length              |
| Status         | Badge           | Awaiting payment, Booked, Cancelled, Completed |
| Actions        | Buttons (small) | Open session; Cancel booking when booked       |

## Data states

| --------------------- | ----------------------- | ----------------------- |

| Completed / cancelled | Open only               | Completed, State Matrix |

## Behavior and accessibility

| Topic     | Rule                                                                           | Source       |
| --------- | ------------------------------------------------------------------------------ | ------------ |
| Structure | An `article` with an `h3`                                                      | WCAG 1.3.1   |
| Status    | A word                                                                         | WCAG 1.4.1   |
| Outputs   | Named `openSession` and `cancelBooking` (a plain `cancel` is a DOM event name) | Angular lint |

## API

| Input or output             | Type             | Default  | Description |
| --------------------------- | ---------------- | -------- | ----------- |
| session                     | `SessionSummary` | required | The session |
| openSession / cancelBooking | `output<string>` |          | Session id  |

## Code

```html
<ui-session-row
  [session]="s"
  (openSession)="open($event)"
  (cancelBooking)="askToCancel($event)"
/>
```
