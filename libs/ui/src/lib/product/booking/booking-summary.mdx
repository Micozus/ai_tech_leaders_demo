# Booking summary

What the mentee is about to pay for.

Backlog: E03-S03 (#27)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '340px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

Before paying, the mentee sees mentor, time, length and total, and that the session is text only (N01).

## When to use

- The payment step and the confirmation.

## When not to use

| Situation           | Use instead                |
| ------------------- | -------------------------- |
| Editing the booking | Go back to the slot picker |

## Anatomy

| Part      | Component        | Notes                       |
| --------- | ---------------- | --------------------------- |
| Container | Card (roomy)     | "Your booking"              |
| Rows      | Description list | Mentor, When, Length, Total |

## API

| Input or output | Type     | Default  | Description  |
| --------------- | -------- | -------- | ------------ | ------ |
| mentorName      | `string` | required | Mentor       |
| when            | `string` | required | Display time |
| length          | `25 \\   | 50`      | required     | Length |
| price           | `number` | required | Price in EUR |
