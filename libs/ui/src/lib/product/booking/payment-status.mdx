# Payment status

The result of paying: awaiting, processing, paid, failed.

Backlog: E03-S03 (#27)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '300px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

A booking is confirmed only after the payment provider confirms.

## When to use

- The payment step of the booking flow.

## When not to use

| Situation      | Use instead   |
| -------------- | ------------- |
| Mentor payouts | Payout status |

## Anatomy

| Part  | Component      | Notes                                  |
| ----- | -------------- | -------------------------------------- |
| Alert | Alert          | Info, success or danger with a heading |
| Retry | Button (small) | "Try another card", failed only        |

## Data states

<Unstyled>
  <Canvas of={Stories.StateMatrix} story={{ height: '900px' }} />
</Unstyled>

| State      | What the person sees                | Story      |
| ---------- | ----------------------------------- | ---------- |
| Awaiting   | Info: "Pay to confirm your booking" | Playground |
| Processing | Info: "Waiting for your bank"       | Processing |
| Paid       | Success: "Booking confirmed"        | Paid       |
| Failed     | Danger alert with retry             | Failed     |

## Behavior and accessibility

| Topic        | Rule                                                  | Source     |
| ------------ | ----------------------------------------------------- | ---------- |
| Announcement | Failure is `role="alert"`, the others `role="status"` | WCAG 4.1.3 |
| Words        | Each state is a heading, not a colour                 | WCAG 1.4.1 |
