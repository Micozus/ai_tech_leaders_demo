# Written answer

The mentor's written answer, shown to the mentee after the session.

Backlog: E04-S02 (#32)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '520px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

The answer is what is kept after the session. It reads at a comfortable measure.

## When to use

- After a session, on the mentee's session page.

## When not to use

| Situation         | Use instead   |
| ----------------- | ------------- |
| The live exchange | Session panel |

## Anatomy

| Part            | Component                   | Notes                                    |
| --------------- | --------------------------- | ---------------------------------------- |
| Container       | Card (roomy)                | "Written answer"                         |
| Author and time | Text                        | Bold author, muted time                  |
| Body            | Text at the reading measure | Line breaks kept                         |
| Privacy         | Text                        | "Only you and the mentor can read this." |

| Error     | Retry                         | Error State |
