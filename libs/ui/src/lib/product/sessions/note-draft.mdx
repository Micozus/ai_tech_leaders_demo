# Note draft

The mentor drafts the session note and sends it for approval.

Backlog: E04-S03 (#33)

## What it is for

R12: the mentor drafts, the mentee approves. Sending is not publishing.

## When to use

- After a session, on the mentor's side; again after a decline.

## When not to use

| Situation             | Use instead   |
| --------------------- | ------------- |
| The mentee's decision | Note approval |

## Anatomy

| Part           | Component        | Notes                                   |
| -------------- | ---------------- | --------------------------------------- |
| Decline notice | Alert (info)     | The mentee's comment, when there is one |
| Note           | Field + Textarea | At least 40 characters                  |
| Send           | Button           | "Send for approval"                     |

## API

| Input or output | Type             | Default | Description            |
| --------------- | ---------------- | ------- | ---------------------- |
| initial         | `string`         | `""`    | Starting draft         |
| menteeComment   | `string`         | `""`    | Comment from a decline |
| sent            | `output<string>` |         | The text to approve    |

## Code

```html
<ui-note-draft
  [initial]="draft()"
  [menteeComment]="comment()"
  (sent)="sendForApproval($event)"
/>
```
