# Note approval

The mentee approves the note in full, or declines it with a comment.

Backlog: E04-S04 (#34)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '620px' }} />
</Unstyled>
<Controls of={Stories.Playground} />

## What it is for

R12: approve in full or decline with a comment; an approved note is kept privately by both, nothing is published.

## When to use

- After the mentor sends a note.

## When not to use

| Situation        | Use instead                             |
| ---------------- | --------------------------------------- |
| Editing the note | Not allowed: no co-editing in 1.0 (R12) |

## Anatomy

| Part     | Component           | Notes                            |
| -------- | ------------------- | -------------------------------- |
| Note     | Text at the measure | The mentor's note                |
| Decision | Radio group         | Approve in full, or decline      |
| Comment  | Field + Textarea    | Required when declining          |
| Submit   | Button              | "Approve note" or "Send comment" |

## Data states

| ----------------------- | ------------------------------------------------------- | ------------------------------------------------ |

| Decline without comment | Error: "Say what to change"                             | Decline Needs A Comment Approve Keeps It Private |

## Behavior and accessibility

| Topic  | Rule                                                               | Source     |
| ------ | ------------------------------------------------------------------ | ---------- |
| Group  | A `fieldset` named "Your decision"                                 | WCAG 1.3.1 |
| Reveal | The comment field appears below the radios; its error is announced | WCAG 3.3.1 |

## Content

| Topic         | Rule                                                                       | Source     |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| Approve       | "Approve the whole note. We both keep it privately; nothing is published." | R12, N02   |
| Decline error | "Say what to change, so the mentor can rewrite the note."                  | WCAG 3.3.3 |

## API

| Input or output     | Type     | Default      | Description                     |
| ------------------- | -------- | ------------ | ------------------------------- |
| note                | `string` | required     | The note                        |
| author              | `string` | Ada Lovelace | Mentor                          |
| approved / declined | `output` |              | Decision (comment for declined) |

## Code

```html
<ui-note-approval
  [note]="note()"
  (approved)="approve()"
  (declined)="decline($event)"
/>
```
