# Access denied

What a person sees on a screen that is not theirs, or when they are signed out.

Backlog: E01-S03 (#19)

<Unstyled>
  <Canvas of={Stories.Playground} story={{ height: '320px' }} />

<Controls of={Stories.Playground} />

## What it is for

Says why the page cannot be opened and gives the way on. The server enforces access; this is only the message.

## When to use

- A signed-in mentee opening a mentor or operator route.
- A signed-out visitor opening a protected route.
- A page that does not exist (same wording, so existence is not revealed).

## When not to use

| Situation                     | Use instead                    |
| ----------------------------- | ------------------------------ |
| A failed load                 | Error state                    |
| An action that is not allowed | Disable it and say why in text |

## Anatomy

| Part      | Component   | Notes                                |
| --------- | ----------- | ------------------------------------ |
| Container | Error state | Heading and description              |
| Way on    | Link        | "Go to your home" or "Go to sign in" |

## Behavior and accessibility

| Topic        | Rule                                                     | Source             |
| ------------ | -------------------------------------------------------- | ------------------ |
| Announcement | `role="alert"` through the error state                   | WCAG 4.1.3         |
| Server       | The route is also denied on the server (403 or redirect) | standards, E01-S03 |
| Focus        | The link is the first focusable element                  | WCAG 2.4.3         |

## Content

| Topic     | Rule                                                                     | Source   |
| --------- | ------------------------------------------------------------------------ | -------- |
| No access | Says whose page it is, not that it is "forbidden"                        | proposal |
| Not found | Uses the no-access wording so the page does not reveal whether it exists | proposal |
