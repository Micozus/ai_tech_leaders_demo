# List with filters

A list a person narrows with filters. The example is the mentor list filtered by stack tag.

Backlog: E03-S01 (#25)

## When to use

- Any list with filters: mentors by stack tag.

## Rules

| Rule                                                                        | Source                |
| --------------------------------------------------------------------------- | --------------------- |
| The count of results is visible and announced when it changes               | task rule, WCAG 4.1.3 |
| Active filters are visible and removable one by one, and all at once        | task rule             |
| "No results for these filters" is a different state from "nothing here yet" | task rule             |
| "No results for these filters" offers Clear filters                         | task rule             |
| "Nothing here yet" says why and, where there is one, offers the next step   | task rule             |
| The list is ordered by availability, never by a score; no search            | R13, N02              |
| Loading shows a skeleton with a status text; an error offers a retry        | task rule             |

## Components used

- Stack tag filter
- Mentor list row
- Async region (loading, empty, error)
- Button

## What to avoid

- Sorting by rating or rank.
- A search box.
- One empty message for both "no results" and "nothing yet".
- A count that is not announced.
