# Note approval

The mentor drafts, the mentee approves in full or declines with a comment.

Backlog: E04-S03 (#33), E04-S04 (#34)

## When to use

- After a session, to keep a note both can find again.

## Rules

| Rule                                                                | Source       |
| ------------------------------------------------------------------- | ------------ |
| The mentor drafts; there is no co-editing                           | R12          |
| The mentee approves the whole note or declines it with a comment    | R12          |
| A decline needs a comment; the mentor sees it first when redrafting | R12          |
| An approved note is kept privately by both; nothing is published    | N02, E04-S04 |

## Components used

- Note draft
- Note approval
- Alert

## What to avoid

- Letting the mentee edit the note.
- Publishing an approved note.
- Declining without saying what to change.
