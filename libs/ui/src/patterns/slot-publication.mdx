# Slot publication

The mentor publishes slots and sees them taken as they are booked.

Backlog: E02-S03 (#22)

## When to use

- The mentor's availability.

## Rules

| Rule                                                     | Source     |
| -------------------------------------------------------- | ---------- |
| Each slot shows Free or Booked as a word                 | WCAG 1.4.1 |
| Only a free slot can be unpublished                      | E02-S03    |
| Publishing is confirmed with a short toast, not an alert | task rule  |
| An empty list says why and offers to publish             | task rule  |

## Components used

- Slot publisher
- Toast
- Badge

## What to avoid

- Unpublishing a booked slot.
- A modal for adding a slot.
- A toast for an error that needs action.
