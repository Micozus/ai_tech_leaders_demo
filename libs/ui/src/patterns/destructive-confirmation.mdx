# Destructive confirmation

Asking before something that cannot be undone. The example is cancelling a booking.

Backlog: E03-S05 (#29)

## When to use

- Cancelling a booking, declining a note, removing a slot with consequences.

## Rules

| Rule                                                                  | Source                |
| --------------------------------------------------------------------- | --------------------- |
| The question names the object                                         | task rule             |
| The way out is easy to find, comes first and takes focus              | task rule, WCAG 3.3.4 |
| The confirming button names the action ("Cancel booking"), never "OK" | task rule             |
| The consequence is written: "the fee is not refunded"                 | R09                   |
| After the decision the page says what happened                        | WCAG 4.1.3            |

## Components used

- Session row
- Confirm dialog
- Cancellation notice

## What to avoid

- "Are you sure?" with "Yes" and "No".
- A destructive button as the default focus.
- Closing the dialog by clicking the backdrop and losing input.
