# Booking flow

Pick a slot, pay, be confirmed. Nothing is confirmed until the payment is.

Backlog: E03-S02 (#26), E03-S03 (#27), E03-S04

## When to use

- Booking a session with a mentor.

## Rules

| Rule                                                                              | Source               |
| --------------------------------------------------------------------------------- | -------------------- |
| A slot under two hours away cannot be chosen, and the reason is written beside it | R14                  |
| Prices of both lengths are shown at the mentor's price                            | R08                  |
| Review shows mentor, time, length (text only) and total                           | N01                  |
| The cancellation rule is shown before paying                                      | R09                  |
| The booking is confirmed only after the payment succeeds                          | E03-S03              |
| A failed payment stays on the payment step with a retry and a reason              | WCAG 3.3.3           |
| The step is always stated: "Step 2 of 3"                                          | WCAG 2.4.8, proposal |

## Components used

- Slot picker
- Booking summary
- Cancellation notice
- Payment status
- Button

## What to avoid

- Confirming before the payment is confirmed.
- Hiding the reason a slot cannot be chosen.
- A promise of how fast the mentor answers (D22).
